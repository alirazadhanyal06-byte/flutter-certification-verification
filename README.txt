FREE SETUP (GitHub Pages)
1. Create a free account at github.com and a new public repository.
2. Upload ALL files (including template.jpg) and the "data" folder.
3. Settings > Pages > Deploy from a branch > main > Save.
   Live at https://YOURNAME.github.io/REPOSITORY/

ADDING A STUDENT
1. Open .../admin.html, enter the student's details, tick what is already done, click Generate.
2. In GitHub: data folder > Add file > Create new file, name it as shown (e.g. NX-XXXX-XXXX.json), paste the text, Commit.
3. Send the student their link (or just their ID).

UPDATING A STUDENT (project submitted / fee paid / test passed)
Open the student's file in the data folder on GitHub, click the pencil icon, change false to true, Commit.

WHAT STUDENTS SEE
- Missing project / fee / test: a polite English + Urdu message saying what is pending.
- Everything complete: "Valid certificate" and a Download button.
- Unknown ID: "Invalid certificate".
